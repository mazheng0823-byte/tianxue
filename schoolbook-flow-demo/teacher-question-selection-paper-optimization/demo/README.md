# Demo

本目录存放教师端挑题组卷优化项目的可运行 Demo 页面。

规则：

- 新页面优先放在这里。
- 根目录不要散落业务页面。
- 如果需要兼容旧地址，可以在根目录放跳转页，但真实页面仍在 `demo/`。

## 页面

| 页面 | 文件 | 状态 |
| --- | --- | --- |
| 原型目录 | `index.html` | 已完成，支持切换 PC 与移动端入口 |
| PC 挑题组卷流程 | `0902-question-list-page.html` | 已完成列表、预览、草稿、编辑、加题/换题和布置设置 |
| 移动端挑题组卷流程 | `0907-mobile-question-list-page.html` | 已完成列表、草稿底部面板、编辑、加题/换题五入口筛选 |

## 适配说明

- 当前复刻页使用 2520 x 1524 固定舞台，并根据浏览器视口等比缩放。
- PC 端不会按宽高分别拉伸，因此页面比例不会变形。
- 移动端页面最大宽度 430px，支持 320px 及以上视口，不产生横向溢出。
