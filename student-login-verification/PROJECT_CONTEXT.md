# 学生账号验证登录 - Project Context

## 项目目标

学校内部封闭 Pad 存在同学恶作剧登录他人账号的情况。通过增加账号验证，限制设备随意登录其他学生账号。

已明确的流程：设备登录其他账号 → 老师发送验证码 → 验证通过后允许登录。

## 当前状态

2026-09-24：已完成机构后台、PC 教师端和移动端三个页面原型，并创建统一目录页。机构后台可配置是否验证登录；教师端可为对应学生生成 4 位验证码，验证码生成后 1 小时内有效。
