# 教师端功能原型

这里收集教师端 PC 与移动端的 HTML 交互原型。所有页面都可直接在浏览器打开，无需安装依赖。

## 在线目录

部署完成后可从 GitHub Pages 目录访问：

`https://mazheng0823-byte.github.io/tianxue/teacher-recycle-bin/`

## 页面列表

- `0824-teacher-recycle-bin-entry.html`：PC 教师端首页与回收站
- `0824-mobile-teacher-recycle-entry.html`：移动端班级页与回收站
- `0826-pc-member-management.html`：PC 成员管理
- `0929-pc-task-share.html`：PC 任务分享
- `0930-mobile-task-share.html`：移动端任务分享
- `0930-pc-assigned-question-filter.html`：PC 已布置试题过滤
- `0930-mobile-assigned-question-filter.html`：移动端已布置试题过滤

从 `index.html` 可进入所有页面。
