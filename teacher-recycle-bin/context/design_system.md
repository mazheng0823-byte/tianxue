# Teacher desktop design system

- Primary: `#2f93ff`; active blue: `#1677ef`; page background: `#dff8ff`.
- Text: `#173252`; secondary text: `#8193aa`; dividers: `#e8eef5`.
- Layout: 56px top bar, 104px left navigation, white rounded workspace panel.
- Radius: 8px controls, 12px cards, 18px main panel.
- Controls: white or pale-blue surfaces, blue outlines, restrained shadows.
- Typography: Microsoft YaHei / PingFang SC; 14-16px body, 18-22px section titles.
- Page pattern: persistent top and left navigation, scrollable center workspace, fixed filter bar.
- Mobile pattern: up to 430px wide, 54px top bar, compact filter row, pale-blue task cards, and a fixed four-item bottom navigation.
