## 版式与间距

- 参考截图：`2520 x 1446`，高 DPI 比例约 `1.75`
- 参考 CSS 视口：约 `1440 x 826`
- 顶栏高度：`50px`
- 左侧导航宽度：`240px`
- 主内容左右留白：约 `19px`
- 表单控件高度：`37px`
- 主操作按钮高度：`33px`
- 表格表头与数据行高度：`57px`
- 组件圆角：`3px` 至 `4px`

## 组件规则

- 顶栏与侧边栏使用深色块，当前导航通过浅一阶背景和左侧蓝线突出。
- 输入框、下拉框、表格均使用细灰边框，不使用装饰性卡片。
- 批量操作统一使用绿色实心按钮，文字为白色。
- 表格采用高密度信息布局，窄列允许中文逐字换行。
- 行内操作使用纯文字按钮；备用密码入口使用蓝色链接。
- 图标保持单色线框风格，不引入彩色装饰。

## 字体

- 字体栈：Arial、Microsoft YaHei、PingFang SC、sans-serif。
- 桌面主字号：`13px`。
- 表头、一级导航和主操作使用加粗字重。
