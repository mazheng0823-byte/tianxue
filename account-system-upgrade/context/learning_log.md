# 原型迭代记录

## 2026-08-20

- 首次建立账号体系升级项目的后台页面视觉基线。
- 用户当前诉求是先复刻参考页面，默认不主动改版或优化视觉。
- 页面属于高密度管理后台，后续新增页面应优先复用深色导航、绿色主操作、浅灰边框表格和紧凑信息布局。
- 账号状态统一使用“未激活、活跃、休眠、停用”，列表通过独立“停用原因”列解释停用状态，其他状态显示 `--`。
- 同一项目可能包含不同来源系统的页面风格；复刻时按页面来源分别保持视觉基线，不强行统一成一套主题。
- 多页面 Demo 使用 `demo/index.html` 作为统一入口，业务页面仍保持独立单文件。

## 2026-08-21

- 学校管理员中心学生列表沿用统一账号状态口径，增加“未激活、活跃、休眠、停用”检索及状态列；列表不展示停用原因。
- 同一检索组内，筛选条件应排在查询按钮之前，查询按钮作为整组条件的最后执行动作。
- 对外发布前需将 Demo 中的姓名、账号、编号、手机号、学校及机构名称统一替换为明确的演示数据。

## 2026-10-13

- 用户数据恢复流程按用户名或用户账号精确匹配，支持 xlsx、csv、tsv；未卸载账号可查看但不可勾选，避免误恢复。
- 恢复数据只更新数据恢复状态，不自动改变账号启用状态。
- 用户数据看板区分当前累计规模与所选周期新增；新增/活跃趋势按日期与省份展示，城市、学校在区域表中逐级下钻。
- 学生六类状态作为独立分布模块呈现，与老师、家长、助教的统一规模趋势并列，避免把学生细分状态误套到其他用户类型。
- 四类用户的全平台当前总量作为固定概览，不随日期或地域筛选变化；新增与活跃指标需通过省份-时间序列展示，而非只列数字。
- 趋势图地域粒度控制在省；市、学校明细放在区域表内，通过省行和市行展开逐层查看，不在筛选栏提供市/学校下拉。
- 学生状态分布也支持省份维度：按省查看六类状态占比，点击省份查看各状态具体人数；汇总视图仍可查看当前区域筛选范围的整体状态。
