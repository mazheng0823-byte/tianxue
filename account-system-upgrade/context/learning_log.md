# 原型迭代记录

## 2026-08-20

- 首次建立账号体系升级项目的后台页面视觉基线。
- 用户当前诉求是先复刻参考页面，默认不主动改版或优化视觉。
- 页面属于高密度管理后台，后续新增页面应优先复用深色导航、绿色主操作、浅灰边框表格和紧凑信息布局。
- 账号状态统一使用“未激活、活跃、休眠、停用”，列表通过独立“停用原因”列解释停用状态，其他状态显示 `--`。
- 同一项目可能包含不同来源系统的页面风格；复刻时按页面来源分别保持视觉基线，不强行统一成一套主题。
- 多页面 Demo 使用 `demo/index.html` 作为统一入口，业务页面仍保持独立单文件。

- 学校管理员中心学生列表沿用统一账号状态口径，增加“未激活、活跃、休眠、停用”检索及状态列；列表不展示停用原因。
